Cómo interpretar los datos

Las etapas proceden de documentación explícita. Las verificaciones describen ejecuciones concretas, no la calidad global. Una fecha antigua no significa abandono. Las prioridades requieren revisión del propietario.

Las tecnologías y los resúmenes se seleccionan manualmente a partir del código y la documentación. Los datos públicos se actualizan cada hora cuando el flujo está habilitado.
