Proyectos

FamilySplitter

Problema: Los gastos de viajes y propiedades familiares necesitan un registro claro de quién debe qué.

Qué desarrollé: Una aplicación mobile-first con React, TypeScript y Supabase, con lógica de reparto en centavos para USD y MXN. Las verificaciones corren en Vitest, Playwright y SQL.

Resultado: CI ejecuta las verificaciones y pruebas de humo en escritorio y móvil. La demo soporta login por enlace mágico y confirmación de pagos en dos pasos.

Ver repositorio

Framework BDD con Playwright

Problema: Empezar pruebas de navegador con BDD implica volver a configurar Playwright Test, objetos de página y flujos de agentes en cada proyecto.

Qué desarrollé: Un scaffold en TypeScript con playwright-bdd, fixtures, objetos de página, un script de preflight y tres definiciones de agentes: planner, generator y healer.

Resultado: El README documenta validación en Chromium. Firefox, WebKit y la ejecución en GitLab aún no están validados.

Ver repositorio

Framework propietario para Saviynt IAM

Problema: Los productos de Saviynt IAM necesitan automatización de pruebas adaptada a sus flujos y entornos.

Qué desarrollé: Un framework propietario en Java con Selenium, Cucumber, TestNG, Maven y Allure, diseñado para adaptarse a cualquier producto de Saviynt IAM.

Disponibilidad: El código está en un repositorio privado. Puedes solicitar una demostración y acceso al repositorio para revisar el framework.
